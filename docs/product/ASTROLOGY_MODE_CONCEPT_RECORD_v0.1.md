## Name

**Astrology Mode**

The name is intentionally whimsical.

Internally, however, Astrology Mode carries a DEAD-serious anti-astrology doctrine.

## Core doctrine

Cuttingboard is not and will never become a prediction engine.

Astrology Mode is an observational structure-and-confluence surface.

It may:

- identify meaningful visual/structural market patterns
- measure repeated reactions
- surface materially bullish or bearish confluence
- show the evidence/homework behind every surfaced observation
- visualize how multiple independent reference systems overlap

It must never:

- declare a future outcome
- imply certainty
- turn visual structure into trade permission
- manufacture probabilities or precision without empirical validation
- convert a pattern into BUY / SELL instruction
- promote chart folklore into fact

**Pointers, not a destination or declaration.**

## Directional confluence

Astrology Mode may surface:

- BULLISH CONFLUENCE
- BEARISH CONFLUENCE

Neutrality is not useful enough to deserve prominent surfacing.

If there is no materially directional structure, Astrology Mode should simply have
nothing important to say.

Directional confluence describes the current evidence.

It does not predict the outcome.

## Homework rule

Every surfaced pattern must expose the evidence that caused it to be surfaced.

Example:

ASTROLOGY MODE — BULLISH CONFLUENCE

Falling-wedge structure developing

Homework:
- upper boundary tested 3x
- lower boundary tested 3x
- range contracting
- 0.618 retracement retested 3x
- VWAP reclaim nearby
- ORB high overlaps same region

What matters:
- acceptance above X strengthens the observed structure
- loss of Y breaks the observed geometry

It must not say:
- target = Z
- 87% breakout probability
- BUY

unless future empirical research independently establishes such a claim.

## Pattern philosophy

A pattern is not a prediction.

A pattern is a compact description of how price is organizing.

Potential structures worth exploring include:

- falling wedge
- rising wedge
- ascending / descending channel
- horizontal balance / range
- volatility compression
- repeated support / resistance tests
- breakout / failed breakout
- higher-low / lower-high compression
- exceptionally clean trend lines

Pattern detection should be deliberately conservative.

It is better for Astrology Mode to say nothing most of the time than to
continually invent visual structures.

## Trend-line doctrine

Trend lines are admissible only under unusually strict standards.

Possible requirements:

- multiple independent touches
- meaningful time separation
- low geometric residual/error
- no cherry-picked endpoints
- repeated reaction around the boundary
- preferably independent confluence
- clear geometric invalidation

A line through two convenient candles is not evidence.

A repeatedly respected boundary may be.

## Fib doctrine

Fib levels are reference systems, not mystical causes.

A fib level by itself carries limited meaning.

What matters is repeated observed behavior and independent confluence.

Example:

A 0.618 retracement that has been tested three times and overlaps:

- VWAP
- prior-day high/low
- ORB boundary
- GEX level
- other independently derived structure

is interesting because market participants are repeatedly reacting to the same
price region.

The repeated reaction and confluence matter more than the label "0.618".

## Confluence principle

Cuttingboard should not highlight a level simply because one indicator produced it.

It should highlight a region when multiple independent systems converge there.

Possible evidence:

- ORB
- VWAP
- PDH / PDL
- prior close
- session high / low
- fibs
- support / resistance retests
- visual structure
- later GEX / dealer positioning levels

The system should show both supporting and opposing evidence.

Example:

| Evidence | Direction |
| --- | --- |
| Falling-wedge compression | Bullish |
| Third 0.618 support reaction | Bullish |
| Above VWAP | Bullish |
| Below PDH | Bearish |
| Large positive-gamma region overhead | Bearish |

Net observed confluence may be described as bullish or bearish.

That still does not imply destination or certainty.

## ORB principle

Prior SPY ORB research did not establish a standalone trading edge.

That does not make ORB structurally useless.

ORB may remain valuable as an observational session landmark:

- developing opening range
- completed opening range
- acceptance above/below
- retests
- interaction with VWAP / PDH / PDL / GEX / other structure

Astrology Mode must never reinterpret this as proof that ORB predicts returns.

## Permission boundary

Pattern recognition and confluence are observational.

They never independently grant:

TRADE

They never override:

NO_TRADE
STAY_FLAT
HALT
operator lock
or any other permission authority.

## Long-term ethos

Cuttingboard combines dense numerical evidence with useful visual representation.

It does not reject visual structure merely because some technical-analysis culture
turns it into superstition.

It also does not accept visual structure merely because it looks compelling.

The goal is:

**observe → measure → show confluence → expose homework → let the human decide**

Never:

**pattern → prediction → declaration**
