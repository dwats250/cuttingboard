# PRD-344 — FRED DGS2/DGS5 fail-fast: one network attempt, truthful timeout diagnostic

ROOT CAUSE
missing fail condition — PRD-336 R3 bounded the FRED request window (`cosd`) and shipped the carrier red test, but had no FAIL line on the failure-path wall-clock cost or on the truth of the failure diagnostic. The generic yfinance retry composition (`config.FETCH_RETRIES` = 3 attempts, `config.FETCH_BACKOFF_SECONDS` = 2, each wrapped in `_run_with_timeout(..., FETCH_TIMEOUT_SECONDS * 3)`) was reused for an OPTIONAL display-only driver, so a hanging endpoint costs about 34 s per series (3 x 10 s socket timeout + 2 x 2 s backoff), about 68 s for DGS2 then DGS5 sequentially (pipeline run 35347796855: 13:02:13Z..13:03:11Z inside a 95 s "Run live pipeline" step). On Python 3.11 (CI) `concurrent.futures.TimeoutError` and `socket.timeout` are both the builtin `TimeoutError`, so `_run_with_timeout` catches the INNER 10 s socket timeout and re-raises it as "fetch timed out after 30s" — a false diagnostic recorded in production logs.

OWNER RULING (Dustin / HELM, 2026-09-18)
DGS2 and DGS5 are OPTIONAL, DISPLAY-ONLY context. No FRED API key; no provider switch; no sticky stale values; no macro-pressure or decision-semantics change. When the public FRED CSV endpoint hangs, fail quickly to the existing unavailable ("--") behaviour instead of retrying optional context for about a minute.

GOAL
Make `_try_fred_quote` in `cuttingboard/ingestion.py` perform exactly ONE network attempt per series using the existing `urlopen` socket timeout (`config.FETCH_TIMEOUT_SECONDS`), with no retry loop and no outer `_run_with_timeout` wrapper, and log the real exception; on any failure return the existing failed `RawQuote` (`fetch_succeeded=False`, `failure_reason` set, `as_of=None`) so normalization drops the driver and the tape renders "--" exactly as today. Successful CSV parsing, the fail-closed parser paths (stale, future-dated, malformed, too few rows, wrong header), and every yfinance/OHLCV retry path are unchanged.

REQUIREMENTS

R1 — Exactly one network attempt per series.
On a `_fetch_fred_csv` failure (any exception, including `TimeoutError`), `_try_fred_quote` calls `_fetch_fred_csv` exactly once, sleeps zero times, and returns `RawQuote(fetch_succeeded=False, as_of=None, source="fred")` with `price == 0.0` (the existing failed-quote shape; no numeric value is fabricated or carried).
FAIL: a test that monkeypatches `_fetch_fred_csv` with a counting callable that raises `TimeoutError` observes `call_count != 1`, or observes `time.sleep` invoked, or observes `fetch_succeeded is True`, or a non-zero `price`. Mutation M1 (restore a two-or-more-attempt loop around the fetch) must turn this test RED.

R2 — Truthful failure diagnostic.
The failure path records the real exception: `failure_reason` contains the raised exception's text, and the WARNING log line contains the exception class name and text; the string "timed out after 30s" (the outer-wrapper message) never appears for a FRED failure.
FAIL: with `_fetch_fred_csv` raising `TimeoutError("timed out")`, `failure_reason` lacks "timed out", or a captured log record for the FRED failure contains "after 30s", or no WARNING record naming the symbol is emitted.

R3 — DGS2 and DGS5 share the behaviour.
R1 and R2 hold identically for `symbol in ("DGS2", "DGS5")` (parametrized).
FAIL: either parametrization fails R1 or R2.

R4 — Success and fail-closed parsing unchanged.
The existing tests `test_try_fred_quote_success_stamps_as_of_and_bounds_url`, `test_stale_fails_closed`, `test_future_dated_fails_closed`, `test_malformed_value_fails_closed`, `test_too_few_rows_fails_closed`, `test_wrong_series_header_fails_closed`, `test_gap_rows_skipped`, `test_parse_latest_and_prior` pass unmodified, and a successful fetch still calls `_fetch_fred_csv` exactly once.
FAIL: any listed test is edited or RED, or the success path shows `call_count != 1`.

R5 — yfinance / OHLCV retry paths untouched.
The `git diff` for `cuttingboard/ingestion.py` contains no hunk outside `_try_fred_quote`; `_run_with_timeout`, `config.FETCH_RETRIES` and `time.sleep` remain referenced by the yfinance/OHLCV paths.
FAIL: `git diff origin/main -- cuttingboard/ingestion.py` shows a hunk whose context is not inside `_try_fred_quote`, or `grep -c "_run_with_timeout(" cuttingboard/ingestion.py` drops below 3 call sites.
