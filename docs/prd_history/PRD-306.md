BUILD-BINDING CONTRACTS

These are the exact contracts the implementer must satisfy. They are the
frozen, review-clean design (packet head 33f753f). Deep rationale stays in
the packet; the numbers/tokens/shapes below are binding.

1. ARTIFACT SCHEMA -- logs/gex_snapshot.json (all keys ALWAYS present on any
   written artifact):
   - schema_version: 1
   - source: "cboe_delayed_quotes"
   - endpoint: exact _SPX URL fetched
   - underlying: "_SPX"
   - roots: ["SPX","SPXW"]  (admissibility allowlist)
   - fetched_at_utc: tz-aware ISO-8601 (producer clock at fetch; locally
     OBSERVED; a naive datetime here is a construction error -> raise)
   - feed_timestamp_utc: provider top-level timestamp re-emitted as tz-aware
     ISO-8601 UTC (e.g. "2026-08-17T18:42:35+00:00")
   - data_delay: "~15 min delayed (REPORTED; Cboe delayed_quotes posture)"
   - spot: {value, basis: "SPX cash index level (data.current_price)"}
   - model_label: "greeks Cboe-model-computed; GEX derived-of-model"
   - sign_convention: "calls:+1 / puts:-1 -- assumed dealer-long-call/short-put
     positioning; descriptive assumption, not measured"
   - units: "USD gamma notional per 1% underlying move"; contract_multiplier: 100
   - gex_total_1pct_usd: net signed GEX total (number)
   - call_wall:  {strike: number|null, gex_1pct_usd: number|null, reason: string|null}
   - put_wall:   {strike: number|null, gex_1pct_usd: number|null (native negative sign retained), reason: string|null}
   - dominant_net_gamma: {strike: number|null, gex_1pct_usd: number|null (signed), reason: string|null}
   - zero_dte: {share: number|null, abs_gex_0dte_1pct_usd: number,
     abs_gex_total_1pct_usd: number, observation_trading_date,
     per_root: {SPX: {abs_gex_0dte_1pct_usd, contracts},
                SPXW: {abs_gex_0dte_1pct_usd, contracts}},
     caveat, reason: string|null}
   - provenance: {configured:[...], observed:[...], reported:[...],
     derived:[...], inferred:[...]} (exhaustive over every emitted top-level field)
   - coverage: {contracts_total, included,
     excluded: {missing_fields, invalid_gamma, invalid_open_interest,
                unparseable_symbol, invalid_expiry, unexpected_root},
     zero_gamma_rows, zero_oi_rows,
     per_root: {SPX, SPXW}, expirations: {count, min, max}}
   The metric key is unified as gex_1pct_usd across call_wall / put_wall /
   dominant_net_gamma. Output must be standard JSON: never NaN/Inf/nonstandard.

2. FORMULAS AND UNITS:
   - Per-contract: gex_contract = sign * gamma * open_interest * 100 * spot^2 * 0.01
     with sign = +1 for calls, -1 for puts; spot = data.current_price (SPX
     cash index level); contract_multiplier 100.
   - Units: USD gamma notional per 1% underlying move (the 0.01 * spot^2
     scaling). Per-1-point (spot^1) is explicitly NOT chosen.
   - OCC strike scaling: strike = parsed strike digits / 1000.
   - Per-strike aggregates: strike_call_gex(k) = sum of gex_contract over
     eligible CALL rows at strike k (each >= 0); strike_put_gex(k) = sum over
     eligible PUT rows at k (each <= 0); strike_net_gex(k) =
     strike_call_gex(k) + strike_put_gex(k) (signed).
   - Structural selection:
       call_wall.strike = argmax_k strike_call_gex(k); value = that max (>= 0).
       put_wall.strike  = argmax_k |strike_put_gex(k)|; value = strike_put_gex
                          at that strike (native negative sign RETAINED).
       dominant_net_gamma.strike = argmax_k |strike_net_gex(k)|; value = signed
                          strike_net_gex at that strike.
     Deterministic tie-break for ALL structural outputs: lowest strike wins on
     equal selection metric.
   - 0DTE: share = numerator / denominator in [0,1] (absolute GEX, so
     cancellation cannot push negative or above 1), or null + reason.
       numerator   = sum |gex_contract| over eligible included contracts whose
                     OCC-parsed expiry == observation trading date.
       denominator = sum |gex_contract| over ALL eligible included contracts
                     (not a window).
       observation trading date = feed timestamp interpreted UTC, converted to
                     America/New_York via stdlib zoneinfo, then .date().
       per_root splits AM-settled SPX vs PM-settled SPXW. AM-vs-PM actual
       settlement timing is NOT modeled in v1; the zero_dte.caveat records this
       and is ALWAYS present.

3. PROVIDER TIMESTAMP CONTRACT (frozen):
   - Provider top-level timestamp is naive text of the exact shape
     "YYYY-MM-DD HH:MM:SS", strictly parsed and interpreted as UTC
     (corroborated against the HTTP Date header posture). Malformed or a
     shape mismatch (e.g. an ISO "T" form) -> fail loud, write nothing, never
     fall back to the producer clock.
   - Re-emitted as tz-aware ISO-8601 UTC in feed_timestamp_utc.

4. VALIDATION / ADMISSIBILITY DOMAIN:
   Top-level (ALL must hold or FAIL LOUD -- exit non-zero, write nothing,
   preserve last good artifact):
   - options exists and is a valid list of contract rows.
   - current_price is numeric, NON-boolean (isinstance bool checked FIRST --
     bool subclasses int), finite (NaN/+-inf rejected), and > 0.
   - top-level timestamp matches the frozen shape above.
   Per-contract (eligible only if ALL hold; any failure EXCLUDES the row and
   increments EXACTLY ONE coverage.excluded reason key; fixed first-failure
   order: missing-fields -> symbol parse -> root -> expiry -> gamma ->
   open_interest):
   - gamma: numeric, non-bool, finite, >= 0 (else invalid_gamma; missing
     gamma/open_interest key -> missing_fields).
   - open_interest: non-bool integer, >= 0 (else invalid_open_interest).
   - OCC option symbol: strict pattern (root, yymmdd, C/P flag, strike*1000);
     type other than C/P fails the strict pattern (else unparseable_symbol).
   - expiry: positionally parseable AND a valid calendar date (month 13 /
     Feb 30 rejected) (else invalid_expiry).
   - root: allowlist SPX/SPXW only (else unexpected_root).
   Degenerate rows with gamma == 0.0 or open_interest == 0 are ADMISSIBLE:
   included (contribute 0) and separately tallied in zero_gamma_rows /
   zero_oi_rows. included == 0 -> FAIL LOUD (exit non-zero, write nothing).
   No proportion thresholds, no silent repair.

5. COVERAGE SEMANTICS:
   coverage counts every contract exactly once. Reconciliation identity
   (asserted): included + sum(excluded.*) = contracts_total. Exactly the six
   exclusion reason keys above; each excluded row increments exactly one
   (first failure in the fixed order). per_root carries per-root contract
   counts; expirations carries {count, min, max}. All coverage counts are
   classified DERIVED.

6. PROVENANCE SEMANTICS (five classes; exhaustive over every emitted
   top-level field):
   - CONFIGURED: schema_version, source, endpoint, underlying, roots, units
     (+ contract_multiplier), and provenance itself.
   - OBSERVED: spot (data.current_price value + basis), feed_timestamp_utc
     (parsed from provider timestamp), per-contract gamma/open_interest inputs
     (never emitted as rows), and fetched_at_utc (locally observed producer
     clock).
   - REPORTED: data_delay (~15-min Cboe delayed_quotes posture).
   - DERIVED: gex_total_1pct_usd, call_wall, put_wall, dominant_net_gamma,
     zero_dte (share/numerator/denominator/observation_trading_date/per_root),
     EVERY coverage count/summary, and the unavailable reason tokens.
   - INFERRED: sign_convention and model_label (assumption-dependent
     interpretive layer). DERIVED outputs are arithmetically exact but inherit
     this INFERRED interpretive layer.

7. UNAVAILABLE / FAILURE SEMANTICS (exact literal reason tokens):
   - call_wall unavailable: "no_eligible_calls" | "no_nonzero_call_gex".
   - put_wall unavailable:  "no_eligible_puts"  | "no_nonzero_put_gex".
   - dominant_net_gamma unavailable (full cancellation): "all_net_gamma_zero".
   - zero_dte zero-denominator: "zero_abs_gex_denominator" (share = null;
     numerator and denominator still emitted as 0 numbers; object stays fully
     present; never 0/0). Outside market hours / a non-expiry day, numerator
     legitimately 0 -> share = 0.0 with reason: null (honest, not an error).
   - Available state everywhere: reason: null; the object keeps its full key
     set (uniform construction).

8. ATOMIC-WRITE / IO BEHAVIOR:
   - One GET per invocation, stdlib only, no retry storm.
   - Serialize to a temp file, then os.replace onto logs/gex_snapshot.json
     (atomic same-filesystem rename).
   - Any provider failure (non-200, non-JSON, malformed top-level structure),
     any validation fail-loud condition, or a mid-write failure leaves the
     PREVIOUS good artifact byte-identical and exits non-zero.
   - zoneinfo unavailable (missing OS IANA tz database) -> FAIL LOUD (no tzdata
     pip dependency introduced).
