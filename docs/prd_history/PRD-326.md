D1-Q1 RULING — OPTION A (ruled: Dustin / HELM, 2026-09-01; from Sol REQ-1)
Background: `select_primary_card_symbol` admits grade C
(`primary_selection.py:35-39`), so when no A+/A/B symbol is chartable the
canonical primary is a C-grade card, and the renderer emits that card inside
`<details class="tier-group" id="tier-c">` (`dashboard_renderer.py:3186-3187`
at base). No change inside `_render_candidate_card` can make that chart
visible. The alternative (narrowing D1 to A+/A/B primaries) was specified,
reviewed by Sol at 7746e4c, and is STRUCK by this ruling.

Ruling text: a C-grade canonical primary must remain eligible for the same
observational primary-chart treatment as any A+/A/B canonical primary.
Therefore:
- when the canonical primary resides inside a collapsed low-tier wrapper, that
  specific enclosing tier defaults OPEN: when a low tier's `tier_syms`
  contains `_primary_card_symbol`, the renderer emits that tier's wrapper as
  `<details open class="tier-group" ...>` (one attribute at
  `dashboard_renderer.py:3186`, roughly 3 net LOC in `render_dashboard_html`);
- the tier remains manually collapsible;
- no secondary chart is automatically opened;
  SUPERSEDED IN PART 2026-09-02 (PRD-329, ruled: Dustin / HELM, Gate A 2026-09-02; GOV-2 s10): this bullet is superseded. Current bullet: "no secondary chart is automatically VISIBLE on page load; inside a closed tier, `level-detail` and `chart-detail` carry `open` so one tier tap reveals them (PRD-329 R1)." Single current authority: docs/prd_history/PRD-329.md; DECISIONS 2026-09-02.
- no secondary candidate receives primary-slot treatment;
- grade, verdict, permission, validation/invalidation, and decision authority
  remain unchanged;
- this is solely the minimum container change necessary to make the canonical
  primary visible under the already-ratified D1 observational rule.

Accepted narrow side effect (recorded by the ruling): other candidate card
identities in that same opened tier may become visible because the enclosing
tier is open. Accepted for D1. Their charts stay behind `chart-detail` (R2).

Not authorized by this ruling: secondary chart opening; candidate-row
redesign; C/D redesign; broader WATCHING changes.

Consequences in this PRD: R10's cone includes exactly the one wrapper hunk; R1
carries the C-grade assertion; the depth walker treats `<details open` as
non-hiding (or a direct attribute assertion is used); fixture
`primary_chart_c_grade` and test `test_prd326_c_grade_primary_tier_opens`
are binding; FOLLOW-UP F1 is struck. Gate A remains Dustin's and is not yet
issued; no implementation may begin.
