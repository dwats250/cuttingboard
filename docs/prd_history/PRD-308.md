PRD-308 — NS-4A Seed Registry: additive universe seed with one observe-only consumer

Status: IN PROGRESS

LANE
STANDARD

CLASS
SIDECAR

WHY NOW
NS-4A is LATER on the North Star ledger; the owner has ratified the smallest
first slice: an ADDITIVE seed registry (not yet the universal source of truth)
that carries a human-authored 12-instrument universe and is read by exactly one
existing observe-only consumer. It lets the watchlist sidecar stop hand-
maintaining its symbol list without touching any decision surface. Design
direction: Dustin's 2026-08-21 NS-4A owner ruling; evidence: PR #264 recon
(audits/ns4a-universe-registry-recon-2026-08/NS4A_UNIVERSE_REGISTRY_RECON_2026-08-21.md,
head 5efed79).

MAX EXPECTED DELTA
Binding ceiling: <= 130 net-added production LOC across exactly two production
files (cuttingboard/universe_registry.py [new], cuttingboard/watchlist_sidecar.py
[modified]). Exactly two test files. Zero new dependencies. Exceeding any of
these stops implementation and requires a PRD amendment + re-review before Gate
A (or an amended Gate A after it), per docs/PRD_PROCESS.md and GOV-2 sec 5.

GOAL
Introduce a frozen, human-authored universe seed registry of 12 owner-ratified
instruments and make watchlist_sidecar source its watchlist rows from that
registry, preserving every unaffected watchlist row value-for-value while
applying exactly the owner-approved membership delta (AAPL removed, GOOG added,
UCO added).

SCOPE
- New module cuttingboard/universe_registry.py: a frozen tuple of 12
  instruments, each carrying symbol, trade_eligible, functions, primary_group,
  enabled, rationale. Human-authored data only; no I/O, no wall-clock, no
  derived semantics, no persisted schema.
- Modify cuttingboard/watchlist_sidecar.py so WATCHLIST_SYMBOLS is DERIVED from
  the registry (via a pure builder) instead of a hand-maintained literal tuple,
  using a documented primary_group -> legacy-theme back-map that reproduces the
  existing coarse theme vocabulary (Index / Commodities / High beta).
- Apply the owner-approved watchlist membership delta only: AAPL removed, GOOG
  added, UCO added (11 rows -> 12 rows).
- Tests: a new registry test file and updated watchlist tests that discriminate
  membership, group assignment, value-for-value preservation, registry sourcing
  (mutation-red), and the one-reader / forbidden-consumer boundary.

OUT OF SCOPE
- The registry is NOT the universal source of truth. No existing universe
  definition is consolidated, removed, renamed, or redirected to it
  (config INDICES/COMMODITIES/HIGH_BETA/MACRO_DRIVERS, TREND_STRUCTURE_SYMBOLS,
  market_map.PRIMARY_SYMBOLS / ASSET_GROUPS, the runtime bare-set literal, the
  correlation/macro alias maps all stay byte-identical).
- No second production consumer. Forbidden as v1 readers: runtime universe
  logic, market_map, regime, qualification, execution, trend_structure, macro
  drivers, heatmap, news, leadership, decoupling, and any GEX surface.
- No new fields beyond the six listed: NO benchmark, horizon, question, news
  sources, provider abstraction, relationship graph, sentiment, score,
  confidence, or LLM-derived value.
- No change to the fetch/scan universe (config.ALL_SYMBOLS). GOOG and UCO are
  NOT added to config; they appear in the watchlist snapshot with
  current_price = null until a later, separate, out-of-scope slice adds them to
  the fetch universe (see R9 realizability note).
- No change to build_watchlist_snapshot's signature or output schema, no change
  to runtime's write path, no decision/qualification/execution behavior change.
- docs/universe_taxonomy.md is NOT updated to claim the registry is canonical
  (that would assert consolidation authority this slice does not carry).

REQUIREMENTS

R1 — Seed registry module
A new module cuttingboard/universe_registry.py defines UNIVERSE_REGISTRY: a
tuple of frozen dataclass instances (@dataclass(frozen=True)), each with exactly
these six fields: symbol: str, trade_eligible: bool, functions: tuple[str, ...],
primary_group: str, enabled: bool, rationale: str. The module performs no I/O,
reads no wall clock, and defines no persisted schema.

FAIL: universe_registry.py is absent, or UNIVERSE_REGISTRY is not a tuple of
frozen dataclass instances, or any entry carries a field outside the six named,
or the module imports an I/O / wall-clock symbol.

R2 — Exact 12-instrument population and delta
UNIVERSE_REGISTRY contains exactly these 12 symbols, each exactly once: SPY,
QQQ, GDX, GLD, SLV, XLE, UCO, NVDA, TSLA, META, AMZN, GOOG. AAPL is absent. GOOG
appears exactly once. UCO appears exactly once.

FAIL: the symbol multiset is not exactly those 12; or AAPL is present; or GOOG
or UCO count != 1.

R3 — Exact primary groups
Every primary_group is a member of the frozen allowed set {INDEX, METALS,
ENERGY, TECH, HIGH_BETA} and equals the owner-approved assignment: SPY=INDEX,
QQQ=INDEX, GDX=METALS, GLD=METALS, SLV=METALS, XLE=ENERGY, UCO=ENERGY,
NVDA=TECH, TSLA=HIGH_BETA, META=TECH, AMZN=TECH, GOOG=TECH.

FAIL: any symbol's primary_group differs from the assignment above, or any
primary_group is outside the allowed set.

R4 — Trade eligibility independent from functions; XLE and UCO not collapsed
trade_eligible is a per-symbol bool (all 12 = True in v1) and is NOT modeled as
a mutually-exclusive role enum. functions is a bounded immutable tuple whose
tokens are drawn only from KNOWN_FUNCTIONS = {"crude_proxy"}. UCO carries
functions = ("crude_proxy",); XLE carries functions = (); so the two ENERGY
instruments are NOT collapsed into one semantic role. No leverage/risk field is
invented.

FAIL: trade_eligible is folded into a role enum; or functions contains a token
outside KNOWN_FUNCTIONS; or XLE and UCO carry identical functions; or any
forbidden field (benchmark, horizon, question, sentiment, score, confidence,
provider abstraction, relationship graph) exists.

R5 — enabled + rationale semantics (no overload, no invented disabled reason)
enabled = True for all 12. rationale carries membership rationale ONLY and is
not overloaded with disabled-state reasoning; there is no separate
disabled-reason field. For the 10 unaffected symbols, rationale equals the prior
watchlist reason byte-for-byte (SPY "broad market reference", QQQ "tech-heavy
reference", GDX "gold miners exposure", GLD "spot gold ETF", SLV "spot silver
ETF", XLE "energy sector", NVDA "AI/semis bellwether", TSLA "retail-flow
signal", META "large-cap tech", AMZN "large-cap tech"). GOOG rationale is a
concise large-cap-technology / market-context string. UCO rationale identifies
it as a crude-oil energy instrument / proxy without asserting exact 1:1 tracking
of CL futures.

FAIL: any of the 12 is disabled, or a disabled-reason field is invented; or an
unaffected symbol's rationale differs from its prior watchlist reason; or UCO's
rationale claims exact CL-futures tracking.

R6 — Watchlist sources the registry (no hand-maintained duplicate)
watchlist_sidecar defines build_watchlist_symbols(registry) ->
tuple[tuple[str, str, str], ...] that maps each ENABLED registry instrument to
(symbol, theme, rationale), and sets WATCHLIST_SYMBOLS =
build_watchlist_symbols(UNIVERSE_REGISTRY). WATCHLIST_SYMBOLS is no longer a
hand-authored symbol literal.

FAIL: WATCHLIST_SYMBOLS is a hardcoded symbol tuple rather than derived from
UNIVERSE_REGISTRY, or build_watchlist_symbols is absent.

R7 — Theme back-map preserves the legacy watchlist vocabulary value-for-value
theme is derived from primary_group by the documented, deterministic map:
INDEX -> "Index", METALS -> "Commodities", ENERGY -> "Commodities",
TECH -> "High beta", HIGH_BETA -> "High beta". The watchlist row shape stays the
3-tuple (symbol, theme, reason). This representation-only normalization
reproduces every unaffected row's (symbol, theme, reason) exactly.

FAIL: any unaffected watchlist row's (symbol, theme, reason) differs from the
pre-change baseline, or the row ceases to be a 3-tuple of non-empty strings.

R8 — Watchlist membership delta is exactly AAPL->GOOG plus UCO
The only differences between the pre-change WATCHLIST_SYMBOLS (11 rows) and the
post-change WATCHLIST_SYMBOLS (12 rows) are: AAPL removed, GOOG added, UCO
added. Insertion order remains serialization-only (PRD-114 R14) and implies no
rank.

FAIL: any membership difference beyond {remove AAPL, add GOOG, add UCO}, or the
post-change count != 12.

R9 — Snapshot schema unchanged; baseline neutral outside watchlist construction
build_watchlist_snapshot's output schema is unchanged: top level
{schema_version: 1, source: "watchlist", generated_at, symbols}, per-symbol
{symbol, sector_theme, watch_reason, current_price}. No production file other
than universe_registry.py and watchlist_sidecar.py changes behavior. Realizability
note: GOOG and UCO are not in config.ALL_SYMBOLS, so their current_price
resolves to null via the existing missing-quote path; the snapshot is written to
logs/watchlist_snapshot.json (a standalone artifact rendered nowhere) so this is
an observe-only, non-decision consequence.

FAIL: watchlist_snapshot.json schema_version or key set changes; or any
non-watchlist pipeline output (config universes, market_map, regime,
qualification, execution, trend, macro) changes; or build_watchlist_snapshot's
signature changes.

R10 — One-reader boundary (forbidden-consumer regression)
universe_registry is imported by exactly one production module:
watchlist_sidecar. No import of universe_registry appears in runtime,
market_map, regime, qualification, execution, trend_structure, macro modules,
heatmap, news, leadership, decoupling, or any *gex* module; and
universe_registry references no GEX surface.

FAIL: any module other than watchlist_sidecar imports universe_registry; or any
forbidden module imports it; or any GEX file imports it; or universe_registry
references a GEX symbol.

R11 — Zero new dependencies; no universe consolidation
No new third-party dependency; universe_registry uses only stdlib (dataclasses,
typing). No dependency file (pyproject.toml, requirements*.txt, setup.cfg)
changes. config.py and runtime universe constants are untouched.

FAIL: any import of a non-stdlib, non-cuttingboard package appears; or a
dependency file changes; or a config/runtime universe constant is edited.

R12 — Discriminating and mutation-red tests
Tests discriminate at least: (A) 12 symbols each once; (B) AAPL absent; (C) GOOG
exactly once; (D) UCO exactly once; (E) primary groups exactly the owner
assignment; (F) all unaffected watchlist rows value-for-value identical to a
frozen pre-change baseline embedded in the test; (G) the only watchlist delta is
{remove AAPL, add GOOG, add UCO}; (H) WATCHLIST_SYMBOLS ==
build_watchlist_symbols(UNIVERSE_REGISTRY) and, per row, reason == rationale and
theme == back-map(primary_group); (I) MUTATION: passing a mutated registry to
build_watchlist_symbols (a changed rationale and a disabled entry) changes a
named watchlist assertion, proving the watchlist is a pure function of the
registry (RED if the watchlist is reverted to a hand-maintained literal); (J)
source scan: no forbidden module imports universe_registry; (K) no GEX surface
imports the registry.

FAIL: any of A-K is absent; or the mutation test (I) still passes when
WATCHLIST_SYMBOLS is reverted to a hand-maintained literal.

DATA FLOW
cuttingboard/universe_registry.py (UNIVERSE_REGISTRY, human-authored)
  -> watchlist_sidecar.build_watchlist_symbols() (filter enabled; map

  -> build_watchlist_snapshot() (unchanged shape)
