BINDING SCOPE NOTE (2026-07-31, connector review of PR #174 — verified)
Restoring the two removed probes is NOT sufficient and must not be this PRD's
requirement. Those probes only established that E402 was enabled and E501 was
disabled; they never proved the resolved set equals the declared
`['E4', 'E7', 'E9', 'F']`. A resolved configuration missing the E7, E9, or F
families entirely — or carrying unrelated extra families while E501 stays off —
satisfies both probes. Restoring them would let this PRD close while the
declaration-to-resolution agreement it exists to prove remains unproved, which
is the same declared-vs-resolved gap in a new costume (PRD-198 invariant 2).

The requirement must therefore compare the COMPLETE resolved rule set against
the expansion of the declared `select`, not spot-check representative rules.
`ruff rule --all` / `ruff check --show-settings` style output is the resolved
source; the declaration is `pyproject.toml`'s `lint.select`. A FAIL line that
passes when a whole declared family is missing is not an acceptable FAIL line.
