GOAL
Render a deterministic static daily-candle setup chart — candles primary,
tiered levels, zone shading, right-edge price tags, `as_of` caption — as
the Market Map's primary spatial representation, with a redesigned
compact tiered ladder as the subordinate exact-level reference and the
honest fallback, preserving every existing authority and lock semantic.

REQUIREMENTS

R1 — Pure chart module with fixed closed tiers
`setup_chart.py` exposes one pure function taking completed bars,
`now_price`, contract entry/stop, `watch_zones`, `fib_levels`, and
operator/decision display flags, returning a deterministic SVG string.
Tier map is FIXED: Tier 1 = NOW (boxed price tag), contract ENTRY, STOP
(risk-zone shading, in-plot bold word labels with the existing signed %
distance); Tier 2 = VWAP, ORB_HIGH/ORB_LOW (band when both), PRIOR_HIGH/
PRIOR_LOW, EMA9, EMA21; Tier 3 = EMA50, fib retracements, drawn only
inside the price domain and never widening the y-scale. No level value is
computed in the module — every rendered price traces to an input.
FAIL: two identical-input calls differ byte-wise; any Tier-3 level widens
the domain (fixture with a distant EMA50 changes the bar-region scale);
any rendered price lacks a corresponding input value; or the module
imports anything from `cuttingboard.runtime`, `cuttingboard.market_map`,
or network/clock modules.

R2 — Bars input, age guard, and honesty
The renderer loads `logs/price_bars_snapshot.json` via a new `_load_*`
-style helper with source provenance; a symbol's bars render only when
the snapshot parses, the symbol is present, and its `as_of` is within 5
calendar days of the renderer's existing `now` parameter; otherwise the
symbol degrades to the compact ladder (R4). The 5-day guard is UTC
calendar-day arithmetic: (UTC date of `now`) minus (`as_of` date) > 5
days -> bars-absent (`now` resolves via the renderer's existing
`now`-or-`_utcnow()` pattern, tz-aware UTC). The chart captions
"bars through <as_of>". OHLC is never synthesized; no partial or padded
candles.
FAIL: a stale fixture (`as_of` 6+ days before `now`) still renders
candles; a missing/corrupt snapshot changes any non-chart output or
raises; the caption is absent while candles render; or any candle value
differs from the fixture bars.

R3 — Candidate presentation and authority preservation
The highest-priority visible setup card renders one full-width chart;
every other candidate's chart sits behind the existing native `<details>`
disclosure (never multiple full charts stacked); the PRD-318 disclosure
keying (`decision_permitted`), `.candidate-observation` dimming, PRD-304
lock neutralization (grey accents, ENTRY->LEVEL, STOP->INVALIDATION, no
action colours under lock), and PRD-226 suppression on invalid
`current_price` all apply to the chart AND to the redesigned compact
ladder in BOTH of its roles — subordinate detail under the chart and the
no-bars/stale fallback — exactly as they applied to the old ladder. The
secondary-card chart disclosure is a NEW wrapper ordered by ruling Q2,
orthogonal to the existing not-permitted `level-detail` wrapper (which
renders only when not `decision_permitted`); both apply per their own
rules. The chart writes nothing and is read by nothing in decision code.
FAIL: depth-aware assertions find two or more full-weight charts outside
disclosure, or a non-permitted render showing any chart outside
disclosure; a locked/halt render shows ENTRY/STOP wording or action
colours in the chart OR in the compact ladder (either role); a candidate
with invalid `current_price` renders a chart or a compact ladder; or
`rg` finds any non-test, non-delivery module importing `setup_chart`.

R4 — Redesigned compact ladder (ruling Q3): subordinate, tier-consistent
The current `_render_level_diagram` presentation is REPLACED by a compact
exact-level reference sharing the chart's tier hierarchy (Tier-1 levels
strongest, Tier-2 clear, Tier-3 faint), rendered as the chart's
subordinate supporting detail (below it or behind disclosure — the
cleanest mobile result decides) and as the full fallback when bars are
unavailable. This DELIBERATELY SUPERSEDES the packet sec4 degradation
line that retained the existing `_render_level_diagram` ladder as the
fallback surface — ruling Q3 governs. The old full-size ladder does not
render anywhere; chart + old-ladder duplication does not occur. The
%-distance facts (PRD-221/222)
and the entry->stop risk representation (PRD-223) remain available in the
compact ladder.
FAIL: any render contains both a chart and the pre-PRD-321 ladder
markup; the no-bars fallback loses the %-distances or entry/stop facts;
or the compact ladder renders Tier-3 levels at Tier-1 weight (styling
assertion).

R5 — Responsive and golden parity
390x844 primary; legible at 360/390/430 with zero horizontal overflow
(viewBox scaling, no fixed widths beyond the SVG max-width); desktop uses
the same SVG wider, no separate chart system; DOM/source order of the
PRD-318 zones unchanged; the golden regenerates mechanically and the
430/431 boundary tests stay green.
FAIL: browser checks show horizontal overflow at any of the three phone
widths; any PRD-318 zone-order test fails; or the golden diff contains
anything beyond the candidate-card region and CSS additions.

R6 — Test quality on the real seams
New/updated tests prove: byte-determinism; tier emphasis vs subdual
(stroke/opacity assertions); source-bar fidelity (bars byte-derived from
fixture); age-guard boundary (5 days exactly, UTC-date arithmetic);
lock/halt/permitted chart states; locked-fallback and
invalid-price-fallback compact-ladder states (R3); disclosure counts;
no-bars fallback; and each guard ships a mutation-verified red test.
FAIL: any listed seam lacks a test that fails under the corresponding
mutation (guard inverted, tier styling swapped, stale render allowed).

DATA FLOW
1. `logs/price_bars_snapshot.json` -> loader (+ age guard vs `now`) ->
   per-symbol completed bars.
2. Existing card facts (current_price, watch_zones, fib_levels, contract
   entry/stop, lock/decision flags) + bars -> `setup_chart` pure function
   -> SVG into the candidate card.
3. Bars absent/stale/invalid -> compact tiered ladder (same facts, no
   candles).
4. Nothing flows back: no payload, contract, or artifact write; no
   decision module import.

FAIL CONDITIONS

semantics; FILES or LOC ceiling exceeded; implementation started before
PRD-320's merge.
