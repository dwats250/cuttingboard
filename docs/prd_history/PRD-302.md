SECURITY MODEL (ratified R.5 smallest lawful claim; packet R.1-R.6, R.11)
Slice A processes only PUBLIC, FIXED, non-sensitive inputs on an ephemeral
GitHub-hosted runner and DOES NOT claim filesystem or runner-credential
confidentiality via `drop-sudo`. Codex `:read-only` grants whole-filesystem
read (`:root = read`, no write, command-network Restricted). Sparse checkout and
working directory are minimization/navigation ONLY, never confidentiality
(R9). Safety rests on: no adversarial ingress (owner-only dispatch + fixed
synthetic event + trusted prompt); `unprivileged-user` credential isolation
(distinct provisioned uid; runner-owned mode-600 credentials not same-uid
readable) proven at the blocking post-merge probe (R6/R7); VERIFIED
`OPENAI_API_KEY` protection (non-dumpable proxy + `env -u` + key-free config --
packet R.3); least privilege (contents:read, no id-token); denied writes/
command-network; no repository-authoritative/issue/PR/comment publication (a
public ~90-day job log and a one-day artifact exist and are acknowledged); zero
authoritative effect.

R7 — Blocking hosted-runner credential-isolation probe (proven post-merge)
A blocking step runs the readability check AS the exact `codex-user` UID, and
FAILS CLOSED (exit 2, no proposal) unless it affirmatively proves denial:
- assert `runner` UID != `codex-user` UID;
- resolve the live runner root deterministically (not a guessed path);
- require `<runner-root>/.credentials` to EXIST with the expected `runner`
  ownership (fail closed if absent, ambiguous, or wrongly owned -- a missing or
  mis-resolved target is NOT proof of denial);
- verify that file (and every target in the enumerated credential set below) is
  UNREADABLE by the `codex-user` UID; never read or print credential contents.
Enumerated credential target set: `<runner-root>/.credentials`,
`<runner-root>/.credentials_migrated`, `<runner-root>/.runner`, and any
`$RUNNER_TEMP/*.credentials`. Mutation-test wrong-user, wrong-path,
missing-file, and readable-file cases (each must make the probe fail).
FAIL: the probe passes while any enumerated runner-owned credential is readable
by `codex-user`; OR the probe passes on an absent/ambiguous/mis-owned target;
OR the readability check is not executed as the exact `codex-user` UID; OR
`runner` UID == `codex-user` UID.
