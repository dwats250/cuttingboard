PRD-334 — Operator-composition dashboard presentation pass

Status: IN PROGRESS

LANE
HIGH-RISK

CLASS
CONSUMER

WHY NOW
Most board components are wired; real operator use exposed hierarchy and
interaction problems (a 30s meta-refresh that resets view state, basic setup
facts hidden behind disclosures, internal-jargon verdict copy, a DETAILS/HISTORY
dumping ground, an even-grid TAPE, an overloaded single-amber palette). This is
one bounded editorial/presentation pass to make the whole page read as one
instrument panel, with zero change to decision, permission, ranking, or data
semantics.

MAX EXPECTED DELTA
<= +450 net production LOC across the three delivery files below (excluding tests
and golden fixtures); no new production module; no new runtime dependency.
Exceeding this stops implementation, amends the PRD with a revised ceiling and
reason, and re-triggers review per the CONSUMER matrix in docs/PRD_PROCESS.md.

GOAL
Recompose the dashboard into a curated seven-region instrument panel — surfacing
what the operator decides on, bounding what is secondary — as a presentation-only
change that translates (never re-authors) every decision-bearing string.

SCOPE
- Remove the automatic page refresh and communicate freshness honestly without new
  polling or persistence machinery.
- Flatten the WATCHING workspace so a selected setup exposes ticker/grade/Level/
  Invalidation/Reason/Watch/chart without a disclosure.
- Humanize the Verdict as a faithful translation layer over the already-resolved
  decision state and permission.
- Humanize the SPY SESSION preamble copy while preserving every observation-state
  branch, ORB state, and the three distinct clocks.
- Recompose the top-level order into: VERDICT / NEXT EVENT / MARKET STRUCTURE /
  SPY SESSION / WATCHING / GEX / HISTORY, with a mandatory pre-edit inventory so no
  existing block is silently dropped.
- Regroup the macro TAPE into market families, renderer-locally.
- Promote the rich Trend Structure table (labeled a curated watch set), retain the
  tradables quote row, home the MARKET MOVEMENT card, delete only truly duplicated rows.
- Re-home and trim Market Control (owner ruling G2).
- Split GEX (production and reference) into a compact summary plus a bounded
  evidence disclosure, hardening synthetic-vs-current disambiguation.
- Introduce a full semantic CSS color-token system (owner ruling G1), separating
  posture/permission color from up/down direction color, with a distinct GEX family.

OUT OF SCOPE
- Any change to TRADE/NO_TRADE/HALT semantics, ranking, qualification, grades,
  primary-selection, setup eligibility, trade permission, MANUAL_CHECK semantics.
- GEX production freshness/validity/suppression semantics; provider architecture or
  acquisition; upstream market logic; Cloudflare scheduling; A1 semantics.
- config.TREND_STRUCTURE_SYMBOLS (no RSP/IWM), config.OPERATOR_LOCK_PERMISSION and
  any shared permission/notification constant, macro_tape_layout.py (shared with
  notifications), select_primary_card_symbol / A1-C intraday-source assignment.
- New data ingestion of any kind. Recorded gaps deferred to future PRDs: US 2Y/30Y/
  USDJPY, RSP/IWM breadth, Trend Structure intraday VWAP, new-board push notification.
- The embedded candidate-chart SVG oracle (`a1c_golden_embedded_svg_sha256` inside
  tests/data/setup_chart_legacy_oracle.json) — must stay byte-identical. Only that
  file's `golden_regions` region-SHA sub-object may be refreshed (see R11).

REQUIREMENTS

R1 — Remove automatic refresh; honest freshness affordance
Delete the `<meta http-equiv="refresh">` emission and the _DASHBOARD_REFRESH_SECONDS
constant. Retain _STALENESS_BANNER_JS and let it re-evaluate on a local-clock
interval (setInterval on the existing IIFE — no new script tag, no network, no
storage). Add an always-visible server-rendered as-of timestamp plus a visible
manual-reload affordance whose copy says a newer board may not exist. The existing
staleness threshold and inactive/unavailable branches are unchanged; the timer never
grants or revokes permission and never revalidates GEX.
FAIL: The rendered HTML contains any `http-equiv="refresh"` meta tag, OR the
staleness threshold constant differs from its pre-PRD value, OR the added timer calls
any network/storage API.

R2 — Flatten the WATCHING workspace
For the selected setup, ticker/grade/lifecycle, Level, Invalidation, Reason, Play,
and Watch render with no enclosing `<details>`; the chart renders flat for every
selected card (the LEVEL MAP -> CHART two-level nesting is removed). MANUAL CHECK
continues to render above the workspace, outside the radio scope. Card flattening
does not change select_primary_card_symbol, chart neutrality, or A1-C intraday-source
assignment.
FAIL: Reason/Play/Watch or the selected-card chart render inside any `<details>`, OR
MANUAL CHECK falls inside the radio-scoped `.setup-panels`, OR the set of symbols
awarded the A1-C intraday chart source differs from pre-PRD output for the same input.

R3 — Verdict is a faithful translation layer (BLOCKER guard)
The visible Verdict sentence and decision-state label are a deterministic translation
of the ALREADY-RESOLVED decision state and permission produced by _decision_title and
the existing decision-state derivation; the renderer authors no claim the state
machine did not establish. The generic no-trade/operator-lock statement reads "No new
trades permitted" without asserting "nothing qualifies"; the existing WHY line carries
the specific reason unchanged; HALT reads "System halted" without inventing a single
cause; halt / coherence / kill-switch information survives even when an operator lock
overlaps; TRADE PERMITTED preserves the long / short / momentum-long distinction from
_regime_to_permission_verb. `data-raw-title`, `data-raw-state`, and
`data-raw-permission` attributes carry the internal canonical values. A new RED test
(tests/test_dash_verdict_translation.py) asserts, per resolved state, that the visible
copy does not contradict the resolved decision state/permission and fails if it does.
FAIL: For any resolved state, the visible Verdict copy asserts a permission or
qualification fact different from the resolved state/permission, OR
tests/test_dash_verdict_translation.py does not fail when the translation is mutated
to a contradicting string.

R4 — Humanized SPY session copy, branches preserved
_spy_session_lines and the clock line render plain-language copy for every existing
branch (OBSERVED, PRE_OPEN prior-session, PRE_OPEN generic, STALE session-mismatch,
STALE generic, UNAVAILABLE), every ORB state, and all three clocks, preserving every
underlying value (price, VWAP relation, read time, ORB, withheld-reason). No value or
state branch is added or removed.
FAIL: Any pre-PRD SPY observation-state branch, ORB state, or clock is absent from the
rendered output for the same input, OR a numeric value visible pre-PRD is dropped.

R5 — MARKET STRUCTURE recomposition (no lost quote coverage)
The macro drivers regroup into families (VOLATILITY / RATES-FX / COMMODITIES / CRYPTO)
locally in the renderer, with the pressure note beside its drivers and "context only"
retained; GC/SI are identified as futures. The rich Trend Structure table is promoted,
labeled "Trend Structure - curated watch set", on the unchanged six-symbol set; the
bland trend chips are removed. The six-symbol tradables quote projection (sourced from
market_map) is retained exactly once, visually distinguished from trend-snapshot
values and not backfilled from another source. The MARKET MOVEMENT card is emitted in
this region with its capture time and existing suppression intact. Only rows duplicated
verbatim elsewhere (macro DRIVER rows already in the family tape) are removed.
FAIL: A macro-family regrouping edit appears in macro_tape_layout.py, OR the six
tradables quotes are absent from the rendered output, OR the Trend Structure table is
populated from any source other than the trend-structure snapshot, OR the MARKET
MOVEMENT card is absent from the output when its pre-PRD suppression conditions are not met.

R6 — Market Control re-home and trim (owner ruling G2)
The current-natured transition and invalidation projections render near SPY SESSION
with their typed-unavailable tokens preserved; the remaining Market Control fields
render inside HISTORY without a standalone six-field card. No cell is silently deleted:
EVENT is removed from the default surface only where NEXT EVENT demonstrably carries
the same producer-resolved event coverage, and candidate-implication counts
(ACTIVE/NEAR_MISS/BLOCKED) remain reachable in HISTORY. No new combined permission is
derived from these cells; market_control_card.py is untouched.
FAIL: transition or invalidation renders only inside HISTORY, OR candidate-implication
counts are absent from the rendered output when present pre-PRD, OR any edit lands in
market_control_card.py.

R7 — GEX summary-first for both fragments; synthetic-vs-current disambiguation
Both the production GEX card and the synthetic reference render a compact summary with
the dense profile (_profile_block: SVG ladder, coverage/spot/outside lines, full
accessible table, methodology) behind a bounded "Full GEX details" disclosure scoped to
its own fragment. The reference keeps an unmistakable "Frozen synthetic SPX example -
not current market data" identity, the model-sign convention, and the SPX/SPY
distinction beside every visible reference number; a current-availability indication is
retained when the production card is suppressed. All PRD-309/333 admission, freshness,
suppression, and isolation guards are unchanged.
FAIL: The production _profile_block renders expanded by default, OR a "Full GEX details"
control toggles a fragment other than the one it labels, OR the synthetic reference
renders without its frozen-example identity beside its numbers, OR any GEX
admission/suppression guard test regresses.

R8 — Full semantic color-token system (owner ruling G1)
Colors are defined as CSS custom properties on :root and referenced by token; amber's
overloaded jobs split into distinct tokens (neutral, warning, flat-posture, grade,
event); posture/permission color is distinct from up/down direction color; the cyan
VWAP-level and "actionable now" double-duty is split; GEX carries a distinct
derivatives family. Every color-carried meaning is also carried by text or shape (color
is never the sole carrier). Token text colors meet WCAG AA against their background.
FAIL: The single amber hex still carries more than one of {neutral, warning,
flat-posture, grade, event} in the emitted CSS, OR any state distinguished only by color
(no text/shape), OR a token text/background pair below AA contrast.

R9 — Whole-page composition; no silent drops (Step 0)

The final top-level order is VERDICT / NEXT EVENT / MARKET STRUCTURE / SPY SESSION /

FAIL: Any top-level block emitted pre-PRD is absent from post-PRD output without a
