SUMMARY
PRD-325 is the bounded design for splitting the hourly `_execute_notify_run`
block at `cuttingboard/runtime/__init__.py:626-662` into an observational
subset (structure, candidates, candidate OHLCV) that runs under STAY_FLAT and a
decision subset (SHORT permission, qualify, continuation audit/promotion,
candidate lines) that stays gated. The architecture, the two-gate necessity,
the notification/contract/run-summary invariance, the network delta, the
shared-artifact consequences, and the out-of-cone test audit all verify
against the code at the reviewed SHA; Helm's STOP condition (primary
reachable only via watch_zones) is NOT triggered. Three claims need correction
before Gate A: R7/R8's fixture is under-specified because candidate formation
(and therefore fib_levels) depends on `direction_for_regime`, which is None
for CHAOTIC/TRANSITION/NEUTRAL-with-net_score-0 regimes; R5's byte-identity
test is vacuous as written because `safe_write_latest` skips a write whose
timestamp equals the existing artifact's; and R10's "at most once per symbol
across the run" is false for the whole run (the derived layer fetches through
its own binding) and must name the spied binding. No implementation diff
exists at the reviewed SHA (`git diff 116a0682..4f8fadde --stat` names only
`docs/PRD_REGISTRY.md`, `docs/prd_history/PRD-325.md`, `docs/prd_index.json`),
