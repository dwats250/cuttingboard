# PRD-341 — Cockpit polish: Market Structure MIX colour + WATCHING compression

- **LANE:** MICRO (Cosmetic Carve-Out, PRD-229 — touches only CSS + presentation
  markup; alters no R12 behaviour surface)
- **CLASS:** cosmetic (display-only)
- **AUTHORITY:** owner charge 2026-09-14 ("Dashboard freshness + market-structure
  light polish"); the freshness/provenance half was split out per the owner's
  ruling (below).

## GOAL

Two display-only refinements to the operator dashboard, each reusing an existing
palette token and an existing markup idiom:

1. **Market Structure restrained colour.** The Trend Structure "curated watch set"
   table gives the `MIXED` alignment token the existing amber accent
   (`--posture-flat`, the `.tape-bias.mixed` hue) so `BULL / MIX / BEAR` read as a
   complete green / amber / red set. MIXED colours the alignment token **only**,
   never the price — a mixed *alignment* is semantically amber, a mixed *price* is
   not. `BULL`/`BEAR` price+alignment colouring is unchanged.

2. **WATCHING card compression.** The low-grade screening card collapses its
   stacked `SYMBOL / BIAS / STRUCTURE` field grid (`.failed-card-fields`) into one
   compact `.card-header` line (mirroring the PRD-249 high-grade header) plus one
   subdued `.screening-note` line, so the chart is the card's visual authority.

## Owner rulings folded in (2026-09-14)

- **PRD-158 §4.2 t11 (low-grade grade-letter suppression) is SUPERSEDED** for the
  compact header, per the owner's explicit charge ("Preserve screening grade/state";
  target line `GLD BEARISH RANGE C`). The screening classification is unchanged —
  only the grade letter's visibility. Precedence: an explicit Helm ruling outranks
  a prior PRD.
- Screening-note **content is preserved verbatim** (`failure_reason` /
  `block_reason` / `reason_for_grade`); only the "SCREENING NOTE" label is dropped.

## Explicitly OUT of scope — deferred to a separate gated PRD

The freshness-banner reword (`BOARD Nh OLD` → `DECISION · Nh`) and the chart-
provenance caption rewrites (daily `_price_bars_caption`, intraday
`intraday_bars._caption`) are **deferred**. They alter dashboard
staleness/source-health truth semantics (R12 "threshold-to-label synthesis" /
"source-health classification") and are coupled to ratified behaviour
(`_spy_clock_line` parses the daily caption's `bars through <ISO>`; PRD-324 R10
requires the intraday caption to state the ET session_date). They therefore need a
STANDARD PRD with Gate A + fresh-context review — not a cosmetic lane — per the
owner's "cosmetic subset now, banner as its own gated PRD" ruling.

## FAIL (deterministic)

A low-grade candidate card must render a `class="card-header"` carrying the grade
letter (e.g. `SPY · C · BEARISH RANGE`) plus a `class="screening-note"` line, and a
`MIXED` trend row must render exactly one `class="ts-px-mix"` (the alignment cell,
never the price). Regression to the pre-polish `.failed-card-fields` stack, or a
coloured MIX price cell, fails the focused tests.
