This artifact records Dustin's final Gate A ruling after the complete OPT-0

## Ruling

OPT-1 Gate A is approved for the **nine-production-file full-truth design**.

Implement at `cuttingboard/options.py::build_option_setups`. When
`risk_per_contract > 0` and the correlation-adjusted quantity is below one,
emit no `OptionSetup`; emit an explicit minimal refusal record instead.

Preserve the list return API and collect refusals through an optional
`refusals` out-parameter. Use exact reason
`SMALLEST_CONTRACT_EXCEEDS_BUDGET` and contract stage `OPTIONS_SIZING`.

Thread the refusal truthfully through:

1. contract `rejections[]`;
2. a purpose-built audit refusal carrier;
3. text report;
4. notification body;
5. HTML delivery;
6. premarket report;
7. postmarket report and aggregate rejected count;
8. CLI transport; and
9. dashboard.

When a sizing refusal is the actual cause, suppress or replace contradictory
generic `no setups` and `no qualifying setups` wording.

Add an end-to-end `_run_pipeline` test proving the same exact token reaches
every required consumer. A mutation that omits the optional out-parameter or
drops any forwarding leg must turn that test red.

## Explicit schema authorization

Exactly two bounded additive schema changes are authorized:

1. add `OPTIONS_SIZING` to the postmarket `rejection_breakdown` exact-key
   schema and include sizing refusals in its existing rejected aggregate;
2. add one dedicated audit refusal field or nested carrier containing the
   stable reason and proving economics.

No top-level contract key, unrelated audit/report field, payload section, or
other schema expansion is authorized.

## Preserved constraints

- no budget, threshold, modifier, strategy-selection, qualification, or
  chain-validation change;
- no fractional contracts or rounding up;
- no dependency or workflow change;
- no unrelated refactor;
- positive sizing remains value-for-value identical for adjusted quantity at
  or above one;
- PRD-023 R2 remains binding: correlation does not alter qualification
  outcomes;
- `size_rounds_to_zero` remains reserved for CB-03 and is not introduced.
