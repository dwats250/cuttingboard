## Ruling

OPT-1 Gate A is approved for the **seven-production-file full-truth design**.

Implement at `cuttingboard/options.py::build_option_setups`. When
`risk_per_contract > 0` and the correlation-adjusted quantity is below one,
emit no `OptionSetup`; emit an explicit minimal refusal record instead.

Preserve the list return API and collect refusal records through an optional
`refusals` out-parameter. Use exact reason
`SMALLEST_CONTRACT_EXCEEDS_BUDGET` and contract stage `OPTIONS_SIZING`.

Thread the refusal through:

1. contract `rejections[]`;
2. audit output;
3. text report;
4. notification body;
5. HTML delivery;
6. premarket report; and
7. postmarket report.

Add an end-to-end `_run_pipeline` test proving the same exact token reaches
every required consumer. A mutation that omits the optional out-parameter or
drops any forwarding leg must turn that test red.

Explicitly authorize exactly one bounded additive schema change:
`OPTIONS_SIZING` is added to the postmarket `rejection_breakdown` exact-key
schema and its pinning test. No other schema expansion is authorized.

## Production ceiling

Exactly these seven production files:

- `cuttingboard/options.py`
- `cuttingboard/runtime/__init__.py`
- `cuttingboard/contract.py`
- `cuttingboard/audit.py`
- `cuttingboard/output.py`
- `cuttingboard/reports/postmarket.py`
- `cuttingboard/reports/premarket.py`

Approximately 160 net production LOC. Any additional production file is a
stop-and-amend event.

## Test surface

The evidence-required tests are those named in PRD-278, including the runtime,
premarket, postmarket, notification, HTML-delivery, contract, audit, and
options-sizing seams. The final asserting set is locked by the PRD-158
pre-implementation grep sweep.

## Preserved constraints

- no budget, threshold, modifier, strategy-selection, qualification, or
  chain-validation change;
- no fractional contracts or rounding up;
- no dependency or workflow change;
- no unrelated refactor;
- positive sizing remains value-for-value identical for adjusted quantity at
  or above one;
- PRD-023 R2 remains binding: correlation does not alter qualification
  outcomes;
- `size_rounds_to_zero` remains reserved for CB-03 and is not introduced.

This ruling authorizes the corrected PRD-278 design surface. Production
implementation remains prohibited until PRD-278 receives its required
