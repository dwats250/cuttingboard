REQUIREMENTS

R1 — Path constant and facade
`cuttingboard/runtime/_constants.py` defines
`PRICE_BARS_PATH = LOGS_DIR / "price_bars_snapshot.json"` beside
`TREND_STRUCTURE_PATH` / `WATCHLIST_PATH`; the runtime facade re-exports
it in the existing re-export block; the full-live harnesses
(`tests/test_notification_ownership.py`,
`tests/test_prd300_delivery_backstop.py`) redirect `PRICE_BARS_PATH`
exactly as they redirect `TREND_STRUCTURE_PATH`;
`tests/test_runtime_package_surface.py` covers the re-export.
FAIL: `PRICE_BARS_PATH` missing from constants or facade; either full-live
harness writes the tracked `logs/price_bars_snapshot.json` during the
suite; or the package-surface test passes with the re-export removed
(mutation check).

R2 — Writer: completed bars only, from frames already in hand
A writer function beside `_write_trend_structure_snapshot` /
`_write_watchlist_snapshot` serializes, per symbol: FIRST filter the
bound `history_by_symbol` frame to rows whose session date is <=
`most_recent_completed_session_date(generated_at)`, THEN take the last
40 of the filtered rows
(`cuttingboard/time_utils.py`), as
`[["YYYY-MM-DD", open, high, low, close, volume], ...]` under the packet
schema: top-level `schema_version: 1`, `generated_at`, `source:
{producer: "hourly"|"daily", provider: "yfinance", interval: "1d",
adjusted: true}`, `columns`, `symbols: {SYM: {as_of, bars}}`. Each seam
(hourly block, daily MODE_LIVE block) binds
`_collect_trend_structure_history(ohlcv)` ONCE to a local and threads the
SAME object into the trend writer and the bars writer — no second
collection, no new fetch.
FAIL: any bar row dated after `most_recent_completed_session_date`
appears in the file; a test fixture frame containing a current-session
row survives into `bars`; either seam calls
`_collect_trend_structure_history` more than once per run (asserted via
call-count stub); or any yfinance/network symbol appears in the writer's
call graph.

R3 — Per-symbol validation, omission, and failure semantics
A symbol whose frame is absent, has wrong columns, or yields zero
completed rows is OMITTED from `symbols` (never partially written); a
writer-level exception is caught and logged (`PRD-278 R8` pattern) and
the run continues; the write is atomic (`.tmp` then `replace`).
FAIL: a malformed frame produces a partial symbol entry or raises out of
the writer; a writer exception fails the run (red test: writer stubbed to
raise -> run summary unchanged); or a non-atomic write path exists (no
tmp-replace).

R4 — Idempotence and as_of truth
For a fixed `most_recent_completed_session_date`, two writer invocations
produce byte-identical `symbols` content (per-symbol `bars` and `as_of`
are pure functions of the frames and the session date); `as_of` equals
the session date of the last written bar per symbol.
FAIL: two same-session invocations differ anywhere under `symbols`; or
`as_of` differs from the last bar's session date in any fixture.

R5 — Transport: tracked fallback + hourly force-add; never restored
`logs/price_bars_snapshot.json` is committed as the tracked fallback
(generated by the real writer over the local cache at implementation
time); the hourly workflow's force-add allowlist gains exactly
`logs/price_bars_snapshot.json`; NO restore-list change in either
workflow; `tests/test_ci_artifact_hygiene.py`'s staged-artifact and
restore-list assertions are updated to pin both facts.
FAIL: the file is untracked (the global `*.json` gitignore silently
swallows a plain `git add` — force-add required); the hourly allowlist
lacks the file or any restore list gains it; or the hygiene test still
passes with the allowlist line removed (mutation check).

R6 — Display-only boundary
No module outside the writer and its tests references `PRICE_BARS_PATH`
or reads `logs/price_bars_snapshot.json` when this PRD closes (the
reader arrives in PRD-321).
FAIL: `rg -l "price_bars_snapshot|PRICE_BARS_PATH" cuttingboard/ tools/
scripts/ ui/` returns any file other than `runtime/_constants.py` and
`runtime/__init__.py`.
