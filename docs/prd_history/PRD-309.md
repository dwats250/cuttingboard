WHY NOW
GEX-1 (PRD-306) produces a cached, delayed `_SPX` gamma-exposure snapshot at
`logs/gex_snapshot.json`, but nothing reads it: the artifact-flow map records
"machine consumers: none". Dustin's free-first product direction ("GEX earns
its pixels") is a cheap, fully-removable, baseline-neutral context card on the
existing dashboard so the snapshot informs the board without changing any
decision. This PRD becomes the FIRST machine reader of that artifact — a pure,
display-only consumer — under the binding product principle: GEX informs the
board; GEX never authorizes the trade.

TARGET INVARIANT / DECISION AUTHORITY
The card is context-only and MUST NOT affect, gate, or couple into any decision
surface. Concretely it must not influence: TRADE / NO-TRADE / HALT, candidate
permission, qualification, grading, ranking, sizing, regime, kill switch,
execution, alert permission, payload coherence (`validate_coherent_publish`),
readiness (`scripts/check_readiness.py`), notification content, audit
requirements, or run success/failure. When no valid GEX artifact is present the
safest failure is ABSENCE: the dashboard is byte-identical to the pre-GEX
baseline. This invariant is enforced by R17 (isolation), R18 (decision-output
invariance), R19 (no readiness marker), and R20 (no renderer-side GEX math).

GOAL
Add a pure, fully-removable, baseline-neutral GEX context card to the dashboard
that reads `logs/gex_snapshot.json` for display only, suppressing to
byte-identical baseline output whenever the artifact is absent, stale, or
out-of-domain, and couples into no decision path.
