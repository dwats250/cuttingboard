FINDING (verbatim from the connector's PR review comment,
`cuttingboard/delivery/dashboard_renderer.py:2274`):

1. **P2 — Preserve halt coloring when artifacts are mixed**
   "When artifact generation IDs are mixed, `render_dashboard_html`
   replaces the authoritative decision title with `MIXED_ARTIFACTS`
   even if `system_halted=True`. This condition therefore selects the
   regime class -- green `sys-up` for `RISK_ON` -- where the previous
   implementation selected `sys-halt`, regressing explicit-halt
   behavior and removing the prominent red halt signal from
   `.sys-verdict`. Preserve the prior halt color for this overlap and
   add a discriminating mixed-artifacts-plus-explicit-halt test."

DISPOSITION (PRD-228 triage; one correction pass, per Dustin's
authorization "one correction pass maximum"):

- Finding 1 — ACTIONED. The finding is correct and squarely inside the
  review's authorized scope (correctness of the `_verdict_cls` fix,
  behavior-preservation) -- a genuine regression PRD-280's own R1
  introduced, not an adjacent idea. `title` is overridden to
  `"MIXED_ARTIFACTS"` whenever `artifact_mixed=True`, independent of
  `system_halted` -- so PRD-280's original `title == "SYSTEM HALT"`
  check silently lost the halt color for a genuinely halted run
  (`system_halted=True`) that also happened to have mismatched
  artifact generation IDs, an orthogonal and independently reachable
  condition. Fixed by ORing the two conditions instead of replacing
  one with the other: `_verdict_cls = "sys-halt" if (bool(system_halted)
  or title == "SYSTEM HALT") else ...` -- `system_halted=True` alone is
  again sufficient (restoring the pre-PRD-280 guarantee), and
  `title == "SYSTEM HALT"` (the PRD-280 fix for status=FAIL/ERROR)
  still applies on top of it. `.decision-state`'s own color for this
  exact overlap remains `sys-flat`/`STATE UNAVAILABLE` by PRD-279's own
  established, separately-reviewed design (its `MIXED_ARTIFACTS` branch
  is checked first and is unreachable from this `_verdict_cls` change) --
  out of this PRD's scope to alter. Verified with a new
  `test_prd280_mixed_artifacts_with_explicit_halt_preserves_halt_color`,
  mutation-confirmed red against the pre-correction (title-only) code,

  renderer.py` (378 tests) passes unmodified otherwise.
