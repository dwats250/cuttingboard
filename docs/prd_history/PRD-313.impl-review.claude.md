### 1. Predicate correctness (R1–R5)
The suppression predicate in `dashboard_renderer.py`:
```
_rf_suppress = (
    isinstance(red_folder, dict)
    and red_folder.get("ok", True)
    and not (red_folder.get("events") or [])
    and not red_folder.get("expiring")
)
if not _rf_suppress: <emit block>
```
Reasoned per input:
- R1 healthy-empty-non-expiring dict `{"ok":True,"error":None,"events":[],"expiring":False}`:
  isinstance→T, ok→T, not([])→T, not False→T ⇒ suppress=True ⇒ block omitted. CORRECT.
- R5 None: `isinstance(None, dict)`→False ⇒ suppress=False ⇒ existing empty-state
  block emitted. None is correctly distinguished from a healthy-empty dict and
  keeps the existing render (owner ruling satisfied). Short-circuit also prevents
  the `.get` AttributeError on None. CORRECT.
- R2 events present: `not ([ev] or [])`→False ⇒ suppress=False ⇒ block emitted. CORRECT.
- R3 error `ok:False`: `red_folder.get("ok", True)`→False ⇒ suppress=False ⇒ block
  emitted with `RED FOLDER UNAVAILABLE`. CORRECT.
- R4 expiring incl empty+expiring `{"ok":True,"events":[],"expiring":True}`:
  `not True`→False ⇒ suppress=False ⇒ block emitted with `nearing expiry`. CORRECT.
- Missing `ok` key defaults truthy (`.get("ok", True)`), matching the pre-existing
  render semantics — no behavior change for that edge.
