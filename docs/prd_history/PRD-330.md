GOAL
Render the dashboard's primary path as VERDICT -> TAPE -> SPY SESSION -> NEXT
EVENT -> WATCHING -> DETAILS with the Proto-B SPY header, a named next-event
strip and a one-line screening summary, and give the SPY chart a zero-JS

NOW, VWAP and the light ORB band and whose LEVELS overlay adds true-price
anchored reference labels, with no change to market facts, permission,
ranking, candidates or the ladder.
