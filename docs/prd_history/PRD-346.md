INFRA + PATCH

ROOT CAUSE
hidden dependency — the helper's GENERATED list was written when the pipelines committed seven tracked files; PRD-194 (per-file ownership), PRD-320/PRD-323 (price-bars / trend-structure / intraday sidecars), PRD-336 (macro drivers snapshot), the hourly `latest_hourly_market_map.json` / `last_hourly_slot.json` carriers, `regime_history.jsonl`, and the rendered `ui/dashboard.html` / `ui/index.html` / `ui/contract.json` were added to the committed set without extending the cleaner. PROJECT_STATE records the resulting leftover dirt as known debt since July.

GOAL
After a normal pipeline/hourly run dirties the tracked generated artifacts, one invocation of `scripts/clean_generated_artifacts.sh` restores every TRACKED generated runtime/display artifact the pipelines commit, and `git status --short` shows none of them modified — while never deleting untracked files, never touching source files, and never touching durable/manual data outside the generated set.

REQUIREMENTS

R1 — Every tracked generated artifact is restored.
After dirtying all seventeen tracked generated paths in a test repo and running the helper, `git status --short` lists none of them.
FAIL: any of the seventeen paths remains modified. Mutation M1 (drop any one path from GENERATED) must turn this test RED for that path.

R2 — Untracked and source files are untouched.
An untracked file and a modified tracked source file (e.g. `cuttingboard/x.py`) present before the run are byte-identical after it, and the untracked file still exists.
FAIL: the untracked file is deleted, or the source file's modification is reverted.

R3 — Fail-loud on a non-git directory.
Run outside a git work tree, the helper exits non-zero (`set -euo pipefail` + git failure) and writes nothing.
FAIL: exit code 0.
