GOAL
After a normal pipeline/hourly run dirties the tracked generated artifacts, one invocation of `scripts/clean_generated_artifacts.sh` restores every MUTABLE tracked generated runtime/display artifact the workflows commit (the seventeen fixed paths below), so `git status --short` shows none of them modified — while never deleting untracked files, never touching source files, and never touching durable/manual data outside that set.
