WHY NOW
CANDIDATE, per the 2026-07-26 DECISIONS ruling on review-artifact replacement. Two checks in tools/validate_prd_registry.py: (1) a COMPLETE PRD's review artifact must pin the commit recorded in the registry's commit cell, not merely some commit on the branch - PRD-273's review pinned a96f16f7 while the PR merged at 8ca1969; (2) a .review.<model>.md file must never be MODIFIED after its first commit - a superseded artifact is renamed to .review.<model>.superseded-<sha>.md and retained, so a closeout reading the working tree sees the full review arc. PRD-273's ACCEPT WITH EDITS artifact with ten blocking findings was overwritten in place by a clean ACCEPT of a different implementation; HEAD showed no trace. Both checks are diffable facts, not judgment calls. Each guard ships a red test (PRD-198 invariant 4).
