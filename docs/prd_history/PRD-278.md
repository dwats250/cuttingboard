ROOT CAUSE
The floor originated in PRD-023 and was preserved by PRD-157. PRD-251's
strategy-aware credit max-loss arithmetic made the latent breach material, and
PRD-256 unified continuation into the same options-sizing block. The current
code can emit one contract even when one contract exceeds the
correlation-adjusted ceiling. The owner ruling supersedes only the floor at
expression. PRD-023 R2 remains binding: correlation must not alter
qualification outcomes.

CHANGE SURFACE
- options.py: refusal dataclass, reason constant, optional refusals parameter,
  and the sizing block replacing the floor.
- runtime/__init__.py: instantiate and pass the refusal list; thread it through
  contract, audit, and report assembly. No decision-gate or kill-switch change.
- contract.py: append OPTIONS_SIZING entries to rejections[].
- audit.py: explicit refusal representation with token and economics.
- output.py: text report line, all-refused notification reason, and HTML payload
  adapter rendering of sections.rejected.
- reports/postmarket.py: add OPTIONS_SIZING to rejection_breakdown and counts.
- reports/premarket.py: state the sizing refusal and do not imply the refused
  setup remains a tradable focus.
