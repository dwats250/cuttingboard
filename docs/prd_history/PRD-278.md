ROOT CAUSE
The floor originated in PRD-023 and was preserved by PRD-157. PRD-251's
strategy-aware credit max-loss arithmetic made the latent breach material, and
PRD-256 unified continuation into the same options-sizing block. The current
code can emit one contract even when one contract exceeds the
correlation-adjusted ceiling. The owner ruling supersedes only the floor at
expression. PRD-023 R2 remains binding: correlation must not alter
qualification outcomes.

CHANGE SURFACE
- options.py: refusal dataclass, reason constant, optional refusals parameter,
  and sizing branch replacing the floor.
- runtime/__init__.py: instantiate/pass the refusal list and thread it through
  every named consumer. No decision-gate or kill-switch change.
- contract.py: append OPTIONS_SIZING entries to rejections[].
- audit.py: one dedicated refusal carrier with token and economics.
- output.py: refusal text, truthful NO_TRADE reason, all-refused notification,
  and HTML payload adapter rendering.
- reports/postmarket.py: breakdown key, sizing count, and truthful aggregate.
- reports/premarket.py: refusal state and no misleading tradable focus.
- delivery/transport.py: CLI output names the refusal, not only its count.
- delivery/dashboard_renderer.py: dashboard states the sizing refusal and does
  not claim there were no qualified setups.
