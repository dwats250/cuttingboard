GOAL
`_verdict_cls` -- which colors both the pre-existing `.sys-verdict`
line and PRD-279's `.decision-state` line -- must key off the already-
authoritative `title` (`_decision_title`'s output) instead of
`system_halted` alone, so a `status=FAIL`/`ERROR` run never renders
`SYSTEM HALT`/`HALT` in a non-halt (e.g. green) color.

SCOPE
One conditional in `render_dashboard_html`: `_verdict_cls`'s
`bool(system_halted)` check becomes `title == "SYSTEM HALT"`. `title`
is already computed earlier in the same function; no new computation.

OUT OF SCOPE
No change to `_decision_title`'s semantics -- it is already
authoritative; this PRD only aligns presentation with it. No runtime/
contract/schema changes; no new halt states/taxonomy; no CSS redesign
beyond the existing `sys-halt`/`sys-up`/`sys-down`/`sys-flat` classes;
no broader dashboard cleanup; no change to PRD-279's R1 mapping, which
already reuses `_verdict_cls` as-is and needs no edit.

REQUIREMENTS

R1 — `_verdict_cls = "sys-halt" if title == "SYSTEM HALT" else
_SYS_VERDICT_CLS.get(str(market_regime), "sys-flat")`. Both
`.sys-verdict` and `.decision-state` render `sys-halt` whenever
`title == "SYSTEM HALT"`, regardless of `system_halted`'s literal
value or `market_regime`.
FAIL: `status` in `{"FAIL", "ERROR"}`, `system_halted=False`,
`market_regime="RISK_ON"` renders `.decision-state` or `.sys-verdict`
with `sys-up` (or any non-`sys-halt` class) instead of `sys-halt`.

R2 — Behavior-preserving for every other case: `system_halted=True`
still resolves `sys-halt` (`_decision_title` always returns
`"SYSTEM HALT"` when `system_halted`); `"TRADE SETUP ACTIVE"` and
`{"NO TRADE", "MONITOR"}` titles still resolve the regime-based class;
`MIXED_ARTIFACTS`/`STATE UNAVAILABLE` (PRD-279's own override)
unaffected; all non-HALT regime coloring unchanged.
FAIL: any pre-PRD-280 `test_dashboard_renderer.py` or
`test_dash_system_state.py` assertion fails.

`status`/`system_halted`/`outcome` -> `_decision_title` (unchanged) ->
`title` -> R1's `_verdict_cls` condition -> `.sys-verdict` and
`.decision-state` classes.
